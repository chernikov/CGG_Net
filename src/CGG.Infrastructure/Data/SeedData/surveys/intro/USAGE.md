# Як використовувати опитувальник «Моя кар'єрна орієнтація»

## Швидкий старт

### 1. Структура опитувальника

```
intro/
├── index.json          # Основна конфігурація
├── step1.json          # Крок 1 з 5 питаннями
├── README.md           # Повна документація
└── USAGE.md           # Цей файл
```

### 2. Інтеграція в додаток

Опитувальник вже інтегрований в систему через:

```
/surveys/definitions/intro.json
```

### 3. Приклад використання

#### Запит опитувальника:
```javascript
const survey = await loadSurvey('intro');
```

#### Отримання питань:
```javascript
const step1 = await loadStep('intro', 1);
const questions = step1.questions;
```

#### Приклад відповідей користувача:
```json
{
  "q1_early_dream": "Q1_HELP",
  "q2_now_matters": "Q2_BAL",
  "q3_motivation": "Q3_CREAT",
  "q4_change_openness": "Q4_MAYBE",
  "q5_self_in_2y": "Q5_STAB"
}
```

#### Відправка на аналіз AI:
```javascript
const result = await analyzeResponses({
  survey: 'intro',
  step: 1,
  answers: userAnswers,
  language: 'uk'
});
```

## Налаштування AI

Опитувальник використовує:
- **Model**: `gpt-5-mini`
- **Provider**: OpenAI
- **Reasoning**: medium effort
- **Verbosity**: medium
- **Output format**: structured JSON

## Підтримка мов

Опитувальник підтримує 3 мови:

- 🇺🇦 **Українська** (uk) — за замовчуванням
- 🇬🇧 **Англійська** (en)
- 🇮🇳 **Гінді** (hi)

Мова відповіді AI автоматично відповідає мові інтерфейсу.
