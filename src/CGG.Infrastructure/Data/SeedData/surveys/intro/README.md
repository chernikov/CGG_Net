# Опитувальник «Моя кар'єрна орієнтація» (Intro)

## Огляд

Пробний тест для батьків, який допомагає зрозуміти їхню професійну орієнтацію, внутрішні мотиви та кар'єрні очікування. Результати аналізуються з психологічної точки зору та показують, як кар'єрні цінності батьків можуть впливати на виховання дітей.

## Характеристики

- **Цільова аудиторія**: Батьки
- **Тип**: Пробний тест
- **Кількість кроків**: 1
- **Кількість питань**: 5
- **Приблизний час**: 5-7 хвилин
- **Мови**: Українська (uk), Англійська (en), Гінді (hi)
- **Формат відповідей**: Single-select (вибір однієї опції)

## Структура питань

### Q1: Мрія на старті кар'єри
**Питання**: Ким ви мріяли стати на початку свого професійного шляху?

**Опції**:
- `Q1_HELP` — Тим, хто допомагає людям (лікар, вчитель, психолог тощо)
- `Q1_BUILD` — Тим, хто створює і будує (інженер, підприємець, майстер)
- `Q1_IDEA` — Тим, хто досліджує і розвиває ідеї (науковець, дизайнер, аналітик)

### Q2: Що найважливіше у професії зараз
**Питання**: Що для вас найважливіше у професії зараз?

**Опції**:
- `Q2_STAB` — Стабільність і дохід
- `Q2_GROW` — Можливість розвитку й самореалізації
- `Q2_BAL` — Баланс між роботою та особистим життям

### Q3: Що вас найбільше мотивує
**Питання**: Що вас найбільше мотивує у роботі?

**Опції**:
- `Q3_RECOG` — Визнання та повага
- `Q3_CREAT` — Творчість і цікаві завдання
- `Q3_ADV` — Кар'єрний ріст і нові можливості

### Q4: Відкритість до змін
**Питання**: Чи відкриті ви до зміни професії або сфери діяльності?

**Опції**:
- `Q4_YES` — Так, повністю
- `Q4_MAYBE` — Можливо, якщо буде потреба
- `Q4_NO` — Ні, хочу залишитись у своїй сфері

### Q5: Як уявляєте себе за 2 роки
**Питання**: Як ви уявляєте себе на роботі через два роки?

**Опції**:
- `Q5_LEAD` — Керую командою чи проектом
- `Q5_STAB` — Працюю у стабільній сфері з передбачуваним доходом
- `Q5_NEW` — Реалізовую себе у новій або більш творчій професії

## Інтерпретація кодів

### Орієнтації (Q1):
- **Q1_HELP** → Допомагаюча орієнтація
- **Q1_BUILD** → Будівельна/підприємницька орієнтація
- **Q1_IDEA** → Аналітична/творча орієнтація

### Цінності (Q2):
- **Q2_STAB** → Пріоритет стабільності
- **Q2_GROW** → Пріоритет розвитку/самореалізації
- **Q2_BAL** → Пріоритет балансу

### Мотивація (Q3):
- **Q3_RECOG** → Мотивація визнанням
- **Q3_CREAT** → Мотивація творчістю
- **Q3_ADV** → Мотивація просуванням

### Відкритість (Q4):
- **Q4_YES** → Висока відкритість до змін
- **Q4_MAYBE** → Помірна відкритість
- **Q4_NO** → Низька відкритість (перевага стабільності)

### Майбутнє бачення (Q5):
- **Q5_LEAD** → Лідерство
- **Q5_STAB** → Безпека/стабільність
- **Q5_NEW** → Новизна/творчість

## Психологічні аспекти аналізу

Аналіз фокусується на:

1. **Тип кар'єрної орієнтації** — допомагаючий, творчий, аналітичний, стабільний тощо
2. **Психологічне ядро** — мотиви, цінності, імпліцитні патерни (стабільність, творчість, автономія, визнання)
3. **Вплив на виховання** — як кар'єрна орієнтація впливає на батьківський стиль та сімейні цінності
4. **Мікроінтерпретація** — темперамент, стиль мислення, особливості мотивації
5. **Зони розвитку** — м'які рекомендації для особистісного зростання та балансу
