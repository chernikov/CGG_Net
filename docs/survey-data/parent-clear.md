# Опитування для батьків (Повний варіант) - Чистий документ

Цей документ об'єднує декілька блоків опитувань, призначених для батьків (профіль батьків, ставлення до дитини, регулярні спостереження та зворотний зв'язок).

---

## Частина 1: Знайомство з батьками
1. Як до вас ми можемо звертатись - Ваше ім’я або псевдонім: *(Відкрите питання)* (можна пропустити)
2. Яких результатів ви очікуєте від використання нашого додатку для своєї дитини? *(Відкрите питання)*
3. Чи є щось важливе, що нам потрібно знати, досліджуючи ваші очікування? *(Відкрите питання)*
4. Скільки у вас дітей? *(Число)*
5. Який вік кожної дитини? *(Числа)*
6. Для якої дитини ви хочете надати інформацію для карʼєрного спрямування? *(Вибір зі списку дітей)*

---

## Частина 2: Ставлення до ролі батьків та кар'єри дитини
1. Який у вас родинний статус щодо дитини? 
   - Мама / Тато / Інший родич / Опікун / Інше
2. Які принципи ви зазвичай застосовуєте у вихованні дитини?
   - Партнерство й діалог / Контроль і структура / Свобода та самовираження / Змішаний підхід / Важко сказати
3. Чим для вас є карʼєрне спрямування дитини?
   - Можливість розкрити таланти / Захист від помилкового вибору / Підготовка до дорослого життя / Те, що має відбутися природно / Інше
4. На скільки ви готові дати свободу дитині у її карʼєрному спрямуванні? *(Оцінка 1–10: 1 — повна свобода, 10 — вже знаю її професію)*
5. Як би ви хотіли долучитися до процесу карʼєрного спрямування?
   - Як спостерігач / Як активний учасник / Як натхненник і ментор / Не планую втручатись / Поки не вирішив(ла)
6. Що для вас найважливіше у розвитку вашої дитини, щоб ми це врахували? *(Відкрите питання)*
7. Що для вас є найбільш важливим у виборі майбутнього кар’єрного напряму дитини?
   - Стабільність / Розвиток талантів / Престиж / Дохід / Інше

---

## Частина 3: Власний професійний досвід батьків
1. Яку професію ви маєте (або мали впродовж життя)? *(Відкрите питання)*
2. Як ви обирали свою професію?
   - За покликанням / За порадою батьків / Через обставини (випадково) / Через матеріальні міркування / Інше
3. Наскільки ви задоволені своїм професійним шляхом? *(Оцінка 1–10)*
4. Що б ви хотіли передати дитині зі свого професійного досвіду?
   - Розуміння важливості стабільності / Уроки помилок / Вміння адаптуватися / Бажання шукати власне / Мені складно відповісти
5. Чи є у вас уявлення про професії, які можуть підійти дитині?
   - Так, є конкретні ідеї / Є загальні міркування / Поки що ні / Не хочу нав’язувати свою думку
6. Якою мірою ви хочете впливати на вибір професії дитини? *(Оцінка 1–10)*
7. Наскільки добре ви орієнтуєтесь у сучасному ринку професій?
   - Дуже добре / В основному орієнтуюсь / Погано / Взагалі не орієнтуюсь
8. Чи довіряєте ви сучасним інструментам для профорієнтації (тестам, платформам, алгоритмам)?
   - Так, це корисно / Частково — з експертним супроводом / Ні — довіряю лише фахівцям або собі / Поки не маю сформованої думки

## Частина 4: Регулярні спостереження (Ремайндери)

### 🗓 Раз на тиждень
1. Чим ваша дитина вас порадувала цього тижня? *(Відкрите поле)*
2. Що нового або цікавого відбулося з дитиною за останні дні? *(Відкрите поле)*
3. Чи був момент, коли ви особливо пишалися дитиною цього тижня? *(Так / Ні + короткий опис)*

### 📅 Раз на місяць
1. За що цього місяця ви найбільше горді за свою дитину? *(Відкрите поле)*
2. Які події чи зміни у поведінці дитини вас приємно здивували? *(Відкрите поле)*
3. Чи було протягом місяця щось у стосунках чи поведінці дитини, що вас насторожило? *(Так / Ні + уточнення)*
4. Які моменти викликали у вас найбільше тепла й розчулення? *(Відкрите поле + оцінка/смайли)*

### ⚡ Ситуативні (позапланові оновлення)
1. **Дитина досягла успіху** (олімпіада, конкурс, спортивна перемога): *Вибір категорії + короткий опис*
2. **Виникла складна чи конфліктна ситуація**: *Вибір (навчання / школа / друзі / сім’я) + короткий опис*
3. **Сталася важлива подія для дитини** (нове захоплення, знайомство, поїздка, нагорода): *Відкрите текстове поле*
4. **Ви помітили різкі зміни у настрої чи поведінці**: *Шкала змін (1–5) + поле для прикладу*

## Частина 5: Очікування від інструменту & Маркетинг
1. Наскільки для вас важливо допомогти дитині визначитися з майбутньою професією? *(Оцінка 1–10)*
2. Які функції профорієнтаційного інструменту є для вас найбільш бажаними? *(Множинний вибір)*
   - Виявити сильні сторони / Показати відповідні професії / Скласти карту інтересів / Надати алгоритм дій / Зменшити тривожність / Дати орієнтири / Інше
3. Що б зробило продукт для вас максимально цінним? *(Відкрите питання)*
4. Чи були б ви готові придбати такий сервіс для дитини?
   - Так, однозначно / Можливо (залежить від ціни) / Сумніваюсь / Ні
5. Що б підштовхнуло вас спробувати продукт?
   - Персоналізований звіт / Консультація / Демоверсія (безкоштовна) / Гарантія / Відгуки / Подарунок-знижка
6. Який формат подачі результатів був би найзручнішим?
   - PDF-звіт / Онлайн-кабінет / Друкована брошура / Інтерактивний додаток / Відео-презентація
7. Яку ціну ви вважаєте прийнятною?
   - До 200 грн / 200–500 грн / 500–1000 грн / Більше 1000 грн / Поки не готовий платити

## Частина 6: Скорочений варіант опитувальника для батьків (А/В вибір)
1. Як дитина зазвичай проводить вільний час?
   - A. Винаходить, майструє, творить, малює
   - B. Дивиться відео, грає, більше споживає контент
2. У нових ситуаціях ваша дитина швидше:
   - A. Вступає в контакт, задає питання
   - B. Спостерігає, тримається осторонь
3. Що більше притаманне вашій дитині?
   - A. Чіткість, послідовність, структурованість
   - B. Гнучкість, імпровізація, легка зміна планів
4. Коли щось не виходить, дитина:
   - A. Спробує ще раз або звернеться по допомогу
   - B. Засмучується, може втратити інтерес
5. Яке середовище найбільш підходить вашій дитині?
   - A. Там, де багато людей, динаміка, обмін думками
   - B. Там, де спокійно, зрозуміло, мало змін
6. Який підхід у навчанні дає кращий результат?
   - A. Практичне застосування, «навчання через дію»
   - B. Спостереження, повторення, вдумливе розмірковування
7. Що з цього точніше про дитину?
   - A. Їй важлива оцінка інших, вона шукає схвалення
   - B. Її більше цікавить власне задоволення від процесу
8. Як дитина реагує на невдачі?
   - A. Переживає, але бере це як виклик
   - B. Сильно засмучується і довго відходить
9. Яка мотивація для дитини сильніша?
   - A. «Я хочу бути кращою, ніж учора»
   - B. «Я не хочу, щоб мене засудили або сварили»
10. Якщо є вибір — що скоріше обере ваша дитина?
    - A. Створити щось нове, навіть ризиковане
    - B. Повторити вже відоме і перевірене

## Частина 7: Детальний аналіз особистості дитини (Загальний блок)
**1. Когнітивні здібності** (Швидкість засвоєння 1-10; Метод запам'ятовування: Повторення/Приклади/Малюнки/Гра; Опис мислення)
**2. Особистісні якості** (Самостійність 1-10; Основні риси: Наполегливість/Відповідальність/...; Які хочете розвинути)
**3. Соціальні навички** (Легкість знайомств 1-10; Комфортне середовище: Компанія/Пара/Наодинці; Вирішення конфліктів)
**4. Психологічні установки** (Дотримання правил 1-10; Головна цінність: Дружба/Успіх/Родина/Комфорт/...; Життєві принципи дитини)
**5. Фізіологічні особливості** (Витривалість 1-10; Улюблена активність: Спорт/Прогулянки/Тихі ігри/...; Медичні нюанси)
**6. Креативність** (Рівень фантазії 1-10; Форми прояву креативності: Малювання/Пісні/Винаходи/...; Приклад нестандартного підходу)
**7. Емоційна регуляція** (Здатність заспокоїтись 1-10; Способи подолання емоцій: Спілкування/Самотність/Гра/Сльози; Основні виражені емоції)

## Частина 8: Демографічний профіль батьків (Додатково)
- Вік / Стать / Країна / Рівень освіти
- Сфера роботи / Посада / Років досвіду
- Основні професійні навички (до 5) / Навички для розвитку / Сильні сторони
- Улюблене дозвілля / Хобі, яке хотіли б монетизувати
- Пріоритети в професії (дохід, баланс тощо) / Відкритість до змін
- Комфортний формат (офіс/віддалено) / Команда чи індивідуальна робота
- Чим задоволені в роботі / Чим не задоволені / Що б змінили / Що залишити незмінним
- Ваші гордості й досягнення (за що варто себе похвалити)
- Додаткові особливості, які ми маємо враховувати.
