# Звіт по порівнянню AB-тесту

## Порівняння вихідних даних (ab-test-clear.md) та Seed-даних бази

В ході порівняння документа `ab-test-clear.md` і бази JSON-файлів (Seed-дані з `step1.json`, `step2.json`, `step3.json`, `feedback.json`) були виявлені **відмінності**:

### Крок 1. Про себе (`step1.json`)

*Відрізняються:*
- У seed-даних відсутні перші три питання із `ab-test-clear.md`: *"Яка твоя електронна пошта?"*, *"Скільки тобі років?"*, *"Яка твоя стать?"*. Тобто seed починається безпосередньо з *"В якій країні ти народився?"* (Q1). Це нормально, оскільки пошта, вік та стать скоріш за все беруться з профілю користувача.

*Збігаються:*
- питання щодо країни, настрою, хобі, звичок, 3 найкращих здібностей, 3 бажаних здібностей, обраної професії, улюбленого героя, антигероя, родичів (улюблені і небажані), бонусні характеристики.

### Крок 2. Поглиблений аналіз (`step2.json`)

*Відрізняються:*
- У питанні про подолання труднощів варіанти відповідей у seed-даних виглядають трохи інакше, ніж у `ab-test-clear.md`: "Підтримка друзів і сім'ї", "Внутрішня мотивація, опора на себе", "Пошук альтернативних, нестандартних рішень", "Аналіз і систематичні зусилля". У `ab-test-clear.md` це: "Підтримка близьких", "Внутрішня мотивація", "Пошук альтернатив", "Аналіз і планування".
- Питання *"Що для тебе найважливіше для досягнення мети? Чому?"* та *"Чого ти хочеш досягнути у житті?"* є текстовими полями (`textarea`) в JSON, хоча в `.md` вони представлені як питання з варіантами вибору (напр.: Кар’єра, Дружба і сім’я тощо).
- Питання про фізичну активність: *Як ти підтримуєш свою фізичну форму?* в JSON - `textarea`, а в `ab-test-clear.md` має чіткі варіанти відповідей.

### Крок 3. Спробуй магію (`step3.json`)

*Відрізняються:*
- У `ab-test-clear.md` питання *Які здібності ти хочеш покращити?* має варіанти: "Творчість", "Комунікація", "Організаційні навички", "Логічне мислення", "Емоційний інтелект", "Інші".
У JSON є: "Комунікація", "Креативність", "Аналітика", "Командна робота", "Емоційний інтелект", "Організація".
- Третє питання у JSON: *"Опиши один конкретний крок, який ти зробиш цього тижня для розвитку."* (textarea). А у md-файлі: *"Введи одну додаткову здібність, яку ти хочеш розвинути."*

### Крок 4. Відгук (`feedback.json`)

*Збігаються повністю:* 
- Питання у `feedback.json` повністю відображають список з `ab-test-clear.md` (наскільки сильною була магічна подорож, опиши її, наскільки вона сподобалась, чому, найскладніші випробування, що покращити). Всі питання ідентичні за змістом і порядком.

## Висновок і Рекомендація
Загалом Seed-дані **практично повністю гармонують** з логікою `ab-test-clear.md` і не потребують негайних жорстких модифікацій, за винятком випадків, якщо вимоги щодо форматів полів (`textarea` замість вибору, і навпаки) є критичними для проекту. Якщо поточні форми (textarea) підходять для АВ-тесту, JSON-файли можна залишити без змін. Оскільки опитувальник АВ-тесту орієнтований на AI-обробку, використання текстових полів замість жорсткого вибору може бути навіть перевагою для `gpt` моделі.
